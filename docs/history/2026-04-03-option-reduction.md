# 2026-04-03 オプションの削減（0.2.0）

> git の履歴（コミットメッセージ）から再構成。

使い始めてすぐ、初期設計で入れたオプションの多くが不要か、launchd 下で動かないと分かったので削った。

| 削ったもの                             | 理由                                                                                                     | コミット  |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------- |
| MCP プリセット（`--mcp slack,linear`） | 固定のプリセットでは足りない。任意の MCP 設定ファイルのパスを渡す `--mcp-config <path>` に置き換えた     | `14d2e4b` |
| `--allowed-tools`                      | 指定しなければ全ツールが許可されるので不要                                                               | `14d2e4b` |
| `--prompt-file`                        | 実行時に `cat` でファイルを読む方式は、launchd 下では TCC に阻まれて失敗する。プロンプトは常に埋め込む   | `5f96325` |
| `--max-turns`                          | claude CLI の既定値で足りる                                                                              | `7fe4366` |
| `remove --purge`                       | ログを残す意味が薄いとして、`remove` は常にログも消すようにした（→ 2026-10-06 に「ログは残す」へ戻した） | `622eb82` |

同時に、`test` に MCP の認証チェック（`claude -p` を実際に流す）を足した（`c06e5ab`）。OAuth トークンの期限切れで定期実行が黙って失敗するのを防ぐため。→ 2026-10-06 に `test` ごと削除。
