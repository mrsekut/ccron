## 書き方

- ファイル名は `YYYY-MM-DD-<短い名前>.md`。
- 「何が困っていたか」「何を決めたか」「何を捨てたか、なぜか」を書く。コードを読めば分かる実装の詳細は書かない。
- 前の判断を覆すときは、どの判断をなぜ覆すのかを書く。
